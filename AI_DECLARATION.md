# AI Declaration

We used AI tools to help write and refine parts of the source code for this project, including implementation details, code structure, and documentation wording.

We did not use AI to decide the project idea, plan how the web app should work, or design how the database should be formed. The database model, tables, relationships, and overall application behavior were planned by us.

We reviewed the generated code and are responsible for the final implementation submitted in this repository.
